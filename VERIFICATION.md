# Проверка консольной редакции 1.1.0

2 октября 2026 года. Обновлён локальный ConsoleDownloader: HTTP(S)-ссылки
любых сайтов вместо ограничения YouTube, сообщения об отказах, семь полных
переводов интерфейса, проверка итоговых файлов через ffprobe.

## Автоматические проверки

Прошли 17 тестов: URL и подписанные параметры, настройки, предел качества,
необязательность JS для прямых файлов, отсутствие ложного успеха, отказ от
коллекций до скачивания, классификация ошибок на всех семи языках.

Шесть интеграционных тестов используют реальные yt-dlp/FFmpeg и локальный HTTP:
MP4 с неизвестной заранее высотой, видео в HTML-проигрывателе, извлечение MP3,
страница без видео, 404, HTML под видом MP4 и проверка реального предела высоты.
Тестовые файлы временные и удаляются автоматически. Без FFmpeg интеграционные
тесты пропускаются; в текущей проверке все шесть выполнены.

## Готовый EXE

Пересобран `dist/YouTubeDownloader/YouTubeDownloader.exe`. Проверены версия,
диагностика, справка для ru/en/es/pt/fr/de/zh и создание меню всех семи языков
в тестовом терминале. Управление мышью не выполнялось.

EXE действительно скачал с локального HTTP-сервера сгенерированный MP4 размером
**19 141 085 байт (18,25 MiB)**. После скачивания FFmpeg полностью декодировал
видео и аудио без ошибок. Проверены совпадение размера и сообщение об ошибке
404 на испанском с кодом выхода 1, без traceback в интерфейсе. Медиа удалены.

В комплекте ffmpeg/ffprobe 9.0.2, Node.js 24.19.0, yt-dlp 2026.08.19.

## Внешняя сеть и ограничения

Пробные прямые ссылки `https://media.w3.org/2010/05/bunny/trailer.mp4` и
`https://storage.googleapis.com/gtv-videos-bucket/sample/ForBiggerFun.mp4`
вернули HTTP 403. Обработчик классифицировал отказ как ограничение доступа;
успешной загрузки с этих адресов не было. Эти проверки не подтверждают
скачивание с YouTube, VK, RuTube или каждого другого внешнего сайта.

DRM, списки видео и текущие трансляции не поддерживаются. При неизвестной
высоте источник сначала скачивается, затем проверяется: слишком высокое видео
остаётся в папке с сообщением об ошибке; выбирайте «Лучшее доступное» для
сохранения исходного качества. Перекодирования в меньшее разрешение нет.
